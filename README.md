Conception d'un jeu pour le cours d'ArchiOWeb et DevMobil à l'HEIG-VD.

Description du jeu:
Vous êtes à Weirdocity, une ville peuplée de « weirdos », des superhéros un peu nuls. Chaque partie débute avec un seul weirdo, dont les cinq compétences sont notées sur une échelle de 1 à 10 et démarrent à un niveau très bas. Pour agrandir sa collection, le joueur doit l’accoupler avec un autre weirdo afin d’en obtenir un nouveau. Le but du jeu est de créer le meilleur weirdo possible, avec les compétences les plus élevées.
